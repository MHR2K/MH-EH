# 修复实验性选项警告和弃用警告

- 作者: MHRobert
- 日期: 2025-09-25
- 提交: 9f5c59f9c2ee33164a431bf64ac07c8df98d10b4

## 变更概述
清理或调整代码中出现的实验性（@OptIn）与弃用（@Deprecated）相关警告：
- 移除不再需要的实验性 API 使用或增加正确的注解说明。
- 替换已弃用方法/字段为推荐实现，降低构建警告数量，提高未来兼容性。

## 影响文件分析（依据文件清单与典型处理）
- app/build.gradle：
	- 调整 Kotlin/Android Gradle 插件或编译参数；
	- 移除不必要的 `-Xopt-in` / 添加明确的 opt-in 目标；
	- 可能升级依赖版本以消除弃用 API。 
- gradle.properties：
	- 添加/移除编译开关（如 JVM 目标、增量编译、警告提升策略）。

### 常见修复方式
1. 用新 API 替换已标记 @Deprecated 的调用；
2. 对仍需使用的实验性 API 添加 `@OptIn` 注解集中声明；
3. 去除局部 suppress，改为结构化的升级/迁移；
4. 最终构建警告数下降，CI 更干净。

### 后续建议
* 建立定期依赖审查脚本，自动提示新弃用；
* 将关键 opt-in 集中在单一“Compatibility”文件，减少散布。
