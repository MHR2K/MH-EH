# 数据导入标签处理优化总结

## 问题背景

在数据导入（备份还原）过程中，下载标签（DownloadLabel）的处理存在以下问题：

1. 导入后标签的排序顺序丢失，特别是手动排序（通过拖拽）后的顺序无法保留
2. 对于不再存在的标签，其下载项需要妥善处理，避免丢失
3. 同名标签的处理需要确保一致性，避免重复

## 实现方案

### 标签导入顺序优化

1. 修改了标签导入机制，确保导入时保留原始时间戳（time 属性）
2. 添加了 `addDownloadLabelWithTime` 方法，专门用于导入时保留标签的原始排序信息

```java
public static synchronized DownloadLabel addDownloadLabelWithTime(DownloadLabel raw) {
    // Reset id
    raw.setId(null);
    DownloadLabelDao dao = sDaoSession.getDownloadLabelDao();
    
    // 确保保留原始时间戳
    if (raw.getTime() <= 0) {
        raw.setTime(System.currentTimeMillis());
    }
    
    raw.setId(dao.insert(raw));
    return raw;
}
```

### 不存在标签的处理

对于导入数据中包含的、但在当前系统中不存在的标签：
- 不再自动创建这些标签（可能是用户已经删除的）
- 将这些标签下的下载项移动到默认列表，确保内容不会丢失

### 同名标签的处理

当导入的标签与已有标签同名时：
1. 检查是否已存在同名标签
2. 如果存在，使用已有的标签，不创建新标签
3. 将导入的下载项关联到已有标签上

```java
public static synchronized DownloadLabel addDownloadLabel(DownloadLabel raw) {
    // Reset id
    raw.setId(null);
    DownloadLabelDao dao = sDaoSession.getDownloadLabelDao();
    
    // 检查标签是否已存在
    QueryBuilder<DownloadLabel> queryBuilder = dao.queryBuilder()
            .where(DownloadLabelDao.Properties.Label.eq(raw.getLabel()));
    List<DownloadLabel> result = queryBuilder.list();
    if (!result.isEmpty()) {
        return result.get(0);
    }
    
    // 保留原始时间戳
    if (raw.getTime() <= 0) {
        raw.setTime(System.currentTimeMillis());
    }
    
    raw.setId(dao.insert(raw));
    return raw;
}
```

## 优化效果

1. **保留排序顺序**：导入后标签的排序顺序与导出前一致，特别是手动排序的顺序也能保留
2. **避免冗余**：已删除的标签不会被重新创建，保持系统整洁
3. **数据完整性**：所有下载项都能正确关联到标签，不会因标签缺失而丢失
4. **一致性**：同名标签会被正确处理，避免出现重复标签

## 技术细节

标签排序使用 `time` 属性（时间戳）来维护顺序，这一机制在整个应用中是一致的：

- `moveDownloadLabel` 方法通过调整 `time` 值来实现标签拖拽排序
- 在导入时保留原始时间戳可确保导入后的排序与导出前一致
- 对于同名标签，优先使用系统中已有的标签，保留其原有排序位置
