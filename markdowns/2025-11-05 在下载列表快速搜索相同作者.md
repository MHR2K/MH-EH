# 在下载列表快速搜索相同作者

- 作者: MHR2K
- 日期: 2025-11-05
- 提交: 53a1ea403ef13b6f33c3120f5b856c98fea07391

## 变更概述
在下载列表中为条目提供“查找同作者”快捷操作，便于快速筛选同一作者的作品。

## 影响文件
- app/src/main/java/com/hippo/ehviewer/sync/DownloadListInfosExecutor.java
- app/src/main/java/com/hippo/ehviewer/ui/scene/download/DownloadsScene.java
- app/src/main/java/com/hippo/ehviewer/ui/scene/download/part/DownloadAdapter.java
- app/src/main/res/menu/download_item_menu.xml
- app/src/main/res/values-zh-rCN/strings.xml
- app/src/main/res/values/strings.xml

## 影响文件分析
| 文件 | 修改要点 |
|------|----------|
| DownloadListInfosExecutor.java | 新增按作者（或 uploader/artist 字段）快速过滤的方法，减少多次全量扫描。可能对数据缓存结构做增补。 |
| DownloadsScene.java | 增加菜单项事件处理：从选中条目提取作者字段，触发过滤刷新；与现有搜索状态互斥或叠加策略。 |
| DownloadAdapter.java | 为条目提供长按/弹出菜单或快捷按钮，传递作者标识给 Scene；可能添加 tag→author 的映射。 |
| download_item_menu.xml | 新增“查找同作者” action id 与图标/标题。 |
| strings.xml / zh-rCN/strings.xml | 增加对应的菜单文本与提示语。 |

### 用户体验提升
1. 一步定位同作者作品，减少手动输入与记忆负担；
2. 结合后续的跨标签/模糊搜索形成多维检索组合；
3. 为潜在的“作者订阅/分组”功能奠定数据与入口基础。

### 回归与边界
* 作者字段缺失时需提示或禁用菜单项；
* 与普通关键字搜索切换时状态清理；
* 大量同作者作品列表滚动性能正常。
