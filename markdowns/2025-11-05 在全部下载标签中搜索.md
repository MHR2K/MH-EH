## 在全部下载标签中搜索功能说明

### 功能概述
在下载列表的搜索对话框中新增“在全部下载标签中搜索”复选框。勾选后，搜索范围从当前标签扩展为所有下载标签中的全部条目，实现跨标签统一搜索。

### 修改文件
1. 布局文件 `app/src/main/res/layout/download_search_dialog.xml`
	- 新增复选框：`@+id/search_all_labels_checkbox`，文本 `@string/search_all_labels`。
2. 字符串资源：
	- 英文 `values/strings.xml`：新增 `search_all_labels = "Search across all labels"`
	- 简体中文 `values-zh-rCN/strings.xml`：新增 `search_all_labels = "在全部下载标签中搜索"`
	- 繁体中文 `values-zh-rTW/strings.xml`：新增 `search_all_labels = "在全部下載標籤中搜尋"`
3. 逻辑文件 `app/src/main/java/com/hippo/ehviewer/ui/scene/download/DownloadsScene.java`
	- 新增成员变量：`mSearchAllLabelsCheckbox`
	- 在搜索对话框初始化中 `gotoSearch()` 里绑定该复选框。
	- 在 `startSearching()` 中：若复选框被勾选，则使用 `DownloadManager.getAllDownloadInfoList()` 返回的全量列表作为数据源，否则使用当前标签对应的列表。

### 运行机制
1. 用户打开“下载”页 → 菜单点击“搜索”。
2. 弹出搜索对话框：输入关键词，可勾选或取消“在全部下载标签中搜索”。
3. 点击“确定”执行搜索：
	- 若勾选：数据源 = 全部下载项列表。
	- 未勾选：数据源 = 当前标签（或默认标签）列表。
4. 其它搜索选项（模糊搜索 / 忽略大小写 / 简繁体转换 / 按相关性排序）继续生效，不受范围切换影响。

### 设计细节
| 选项 | 作用 | 备注 |
|------|------|------|
| 在全部下载标签中搜索 | 扩展搜索范围到所有标签 | 默认不勾选，不持久化 |
| 模糊搜索 | 启用模糊匹配 | 勾选后可启用“按相关性排序” |
| 忽略大小写 | 关闭大小写敏感 | 内部通过取反得到 `caseSensitive` 标志 |
| 简繁体转换 | 对标题做简繁体归一 | 可提高汉字匹配命中率 |
| 按相关性排序 | 基于匹配评分排序 | 仅在模糊搜索开启时可用 |

### 容错与兜底
在读取全量数据源时若出现异常（极少），自动回退到当前标签列表进行搜索，不中断用户操作。

### 未做与可选优化
1. 暂未持久化复选框状态（下次打开默认关闭）。
2. “查找相同作者”功能尚未接入全标签搜索开关（当前仅基于当前标签列表）。
3. 可增加对搜索范围的结果统计提示（例如：显示“跨 X 个标签搜索到 Y 条结果”）。
4. 可在 `Settings` 中加入全标签搜索的默认启用配置。

### 后续可扩展建议
1. 添加持久化：`Settings.putSearchAllLabelsEnabled(boolean)`。
2. 作者快捷搜索支持“全标签”复选框同步联动。
3. 搜索结果高亮匹配文本（需在适配器中增加渲染逻辑）。
4. 大数据量场景下（全量超大）可考虑加入异步增量结果展示。

### 验证要点
| 验证项 | 期望结果 |
|--------|----------|
| 未勾选复选框搜索 | 仅当前标签列表中匹配 |
| 勾选复选框搜索 | 全部标签合并后匹配，结果数应 ≥ 当前标签搜索结果数 |
| 切换模糊搜索状态 | “按相关性排序”可用性同步变化 |
| 勾选简繁体转换 | 简体/繁体关键词均能命中同一条目 |
| 忽略大小写 | 大小写不同的关键词不影响匹配 |

### 代码片段（核心数据源选择）
```java
List<DownloadInfo> dataSource = mList;
if (mSearchAllLabelsCheckbox != null && mSearchAllLabelsCheckbox.isChecked()) {
	 Context ctx = getEHContext();
	 if (ctx != null) {
		  DownloadManager dm = EhApplication.getDownloadManager(ctx);
		  if (dm != null) {
				dataSource = dm.getAllDownloadInfoList();
		  }
	 }
}
DownloadListInfosExecutor executor = new DownloadListInfosExecutor(
		  dataSource, searchKey, fuzzySearch, caseSensitive, enableChineseConversion);
```

### 总结
此次改动以最小入侵方式实现跨标签搜索：只在对话框新增一个复选框并在搜索入口调整数据源，未影响现有分页、过滤、排序与选择模式逻辑，兼容已有搜索选项。可在后续迭代中继续增强可用性与性能体验。
